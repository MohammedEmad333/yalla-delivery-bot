# يلا ديلفري — بوت واتساب (Yalla Delivery WhatsApp Bot) 🛵

بوت واتساب لخدمة عملاء **Yalla Delivery** مبني على Node.js و
[Baileys](https://github.com/WhiskeySockets/Baileys).

> **مهم:** إنشاء طلبات التوصيل مباشرةً عبر واتساب غير متاح. جميع الطلبات تُنشأ من
> تطبيق Yalla Delivery فقط.

## المزايا
- يرسل روابط تطبيق يلا ديلفري للعميل ويحوّل أي طلب جديد إلى التطبيق.
- يجيب عن الأسئلة العامة المتعلقة بالأسعار والمناطق.
- يوفّر معلومات التواصل مع الدعم.
- لا يجمع الاسم أو العنوان أو تفاصيل الشحنة أو بيانات الدفع لإنشاء طلب.
- لا يحفظ طلبات في `orders.json` ولا يرسل طلبات إلى Yalla API.
- ربط برمز اقتران (Pairing Code) أو QR، مع إعادة اتصال تلقائية وحفظ الجلسة.
- سيرفر Express لإبقاء الاستضافة نشطة + `/health` و`/qr` و`/ai-status`.
- 🤖 مساعد ذكي عبر Google Gemini أو Groq مع ذاكرة محادثة قصيرة، حماية من إساءة الاستخدام،
  تحويل تلقائي للمزوّد الاحتياطي عند توفره، وتعليمات صريحة بعدم إنشاء الطلبات عبر واتساب.
- تنظيف تلقائي للجلسات الخاملة حتى تبقى ذاكرة الخدمة مستقرة مع التشغيل الطويل.
- **تدخل بشري تلقائي:** إذا ردّ صاحب حساب واتساب يدوياً على عميل، يتوقف البوت والـAI عن الرد على ذلك العميل فقط، ويستمران مع باقي العملاء. يعود الرد الآلي تلقائياً بعد مدة قابلة للضبط عبر `HUMAN_TAKEOVER_MIN` (الافتراضي 30 دقيقة).
- **تصعيد ذكي:** طلب الموظف/الإنسان صراحة أو تكرار مشكلة الدعم يحوّل المحادثة للتدخل البشري تلقائياً. يمكن ضبط حد التكرار عبر `SMART_ESCALATION_REPEAT`.
- **حلول أعطال شائعة:** ردود موثوقة لمشاكل تسجيل الدخول، رمز التحقق، تعطل التطبيق، الدفع/المحفظة، الطلب المتأخر، والموقع.
- **إحصائيات تشغيلية بدون حفظ محتوى الرسائل:** عدد الرسائل، ردود AI، الدعم، التصعيدات، وروابط التطبيق.
- يمكن للعميل كتابة `/reset` أو **ابدأ من جديد** لمسح سياق المحادثة والبدء من جديد.

## تجربة العميل
القائمة الرئيسية:
- **1** فتح/تحميل التطبيق.
- **2** الاستفسار عن الأسعار والمناطق.
- **3** التواصل مع الدعم.

كما أن كلمات مثل **طلب**، **طلب جديد**، **توصيل** و**order** تعيد رابط التطبيق بدل
بدء تدفق طلب داخل واتساب.

## المساعد الذكي
يدعم مزوّدَين — يكفي مفتاح واحد:

**Google Gemini**
1. احصل على مفتاح من [Google AI Studio](https://aistudio.google.com/apikey).
2. أضف `GEMINI_API_KEY` في `.env`.

**Groq**
1. احصل على مفتاح من [Groq Console](https://console.groq.com/keys).
2. أضف `GROQ_API_KEY` في `.env`.

يمكن اختيار المزوّد عبر `AI_PROVIDER=auto|gemini|groq`، وضبط الذاكرة وحد المعدل
عبر `AI_MEMORY_TURNS` و`AI_RATE_MAX`. ويمكن ضبط `AI_MAX_INPUT_CHARS` للحد
الأقصى لطول السؤال و`AI_SESSION_TTL_MIN` لمدة الاحتفاظ بجلسة العميل الخاملة.

### أوامر الإدارة
- `/حالة` أو `/ai`: حالة المساعد وفحص حي للمزوّد.
- `/stats` أو `/إحصائيات`: إحصائيات التشغيل الحالية.
- `/محادثات`: المحادثات الموجودة حالياً تحت التدخل البشري.
- HTTP: `GET /ai-status` يعرض حالة AI وإحصائيات البوت.

> الإحصائيات التشغيلية تبدأ من آخر تشغيل للخدمة، ولا تحفظ نصوص رسائل العملاء.

## التشغيل محلياً
```bash
npm install
npm start
```

### الربط بالواتساب
الطريقة الافتراضية رمز اقتران لرقم الأعمال:
1. شغّل `npm start`.
2. واتساب ← الأجهزة المرتبطة ← ربط جهاز ← ربط برقم الهاتف بدلاً من ذلك.
3. أدخل الرمز الظاهر في الطرفية.

للربط عبر QR اضبط `USE_PAIRING_CODE=false`.

## الإعدادات
```bash
cp .env.example .env
```

عدّل رقم الأعمال، رقم الدعم، وروابط التطبيق، ثم أضف مفتاح AI عند الحاجة.

## المسارات
- `/` حالة الخدمة.
- `/health` فحص الصحة.
- `/qr` عرض QR عند استخدامه.
- `/ai-status` تشخيص المساعد الذكي.
