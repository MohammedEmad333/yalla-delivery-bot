# يلا ديلفري — بوت واتساب (Yalla Delivery WhatsApp Bot) 🛵

بوت واتساب تفاعلي مستقل لاستقبال طلبات التوصيل آلياً (طعام 🍔 / طرود 📦 / بقالة 🛒)،
مبني على Node.js و [Baileys](https://github.com/WhiskeySockets/Baileys).

## المزايا
- تدفق محادثة تفاعلي متعدد الخدمات مع آلة حالات لكل عميل.
- يجمع: الاسم، المصدر، التفاصيل، عنوان التسليم، الجوال، طريقة الدفع، وقت التوصيل.
- يحثّ العميل على تحميل التطبيق (أندرويد/آيفون).
- يحفظ الطلبات محلياً في `orders.json` (بلا أي API خارجي).
- ربط برمز اقتران (Pairing Code) أو QR، مع إعادة اتصال تلقائية وحفظ الجلسة.
- سيرفر Express لإبقاء الاستضافة نشطة + عرض QR/الطلبات على الويب.

## التشغيل محلياً
```bash
npm install
npm start
```

### الربط بالواتساب
الطريقة الافتراضية **رمز اقتران** لرقم الأعمال (`BUSINESS_NUMBER`):
1. شغّل `npm start` وسيظهر رمز من 8 خانات في الطرفية.
2. على هاتف رقم الأعمال: واتساب ← **الأجهزة المرتبطة** ← **ربط جهاز** ← **ربط برقم الهاتف بدلاً من ذلك** ← أدخل الرمز.

للربط بمسح QR بدلاً من ذلك اضبط `USE_PAIRING_CODE=false` وامسح الرمز من الطرفية أو من `http://localhost:3000/qr`.

## الإعدادات
انسخ `.env.example` إلى `.env` وعدّل القيم (الأرقام، روابط التطبيق...).

## المسارات
- `/` حالة الخدمة — `/health` فحص صحة — `/qr` عرض QR — `/orders` عرض الطلبات.

## النشر
جاهز للرفع على Render أو Alwaysdata (Build: `npm install` / Start: `npm start`).

> ملاحظة: على الاستضافات ذات القرص المؤقت قد يُمسح `auth_info` و`orders.json` عند إعادة النشر — استخدم قرصاً دائماً للحفاظ على الجلسة.
